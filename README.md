# L2D Viewer

静态 Live2D 模型查看器。支持从本地文件夹添加 Cubism 模型、在同一画布显示多个模型，以及查看、编辑和交换姿势参数。读取的模型文件留在浏览器中。

## 运行

无需安装 npm 依赖或构建。在仓库目录运行：

```sh
python3 -m http.server 8765
```

用支持文件夹选择和 WebGL 的浏览器打开 `http://localhost:8765/`。浏览器需要加载 jsDelivr 上的 PixiJS 和 Live2D 适配器，以及 Live2D 官方站点上的 Cubism Core。

要试用仓库中的三个样本，可在页面上一次导入整个 `resources` 文件夹，再为各模型选择并播放动作。

## 使用

1. 点「导入文件夹」，选择包含 `.model3.json`、`.moc3` 及其所引用贴图和动作等文件的文件夹。可以选择包含多套模型的上级文件夹，也可以反复添加。旧版 `.model.json` 暂不支持。
2. 点击画布中的模型区域或下方的模型名称。通过动作下拉框选择要播放的动作，各模型独立播放。
3. 参数面板显示渲染姿势的实时数值。点「暂停」后用滑块或数值框编辑。「重置参数」恢复模型定义的默认值并保持暂停。继续播放会从暂停的时间点恢复。
4. 在「JSON 快照」中导出可复制的 JSON 文本，或粘贴文本后导入。格式为 `{"ParamAngleX": 10}`。导入会先校验全部键和值，再暂停并应用。可只提供要调整的参数，数值必须在当前模型允许的范围内。

## 结构

- `src/local-model-source.js` 发现本地模型，通过模型文件的相对路径解析资源。
- `src/live2d-model.js` 封装渲染适配器、单模型播放状态、姿势参数和快照。
- `src/scene.js` 管理同屏布局和模型生命周期。
- `src/parameter-panel.js` 渲染参数面板。`src/main.js` 连接导入、场景和页面控件。

未来的远端模型列表可以生成同样的模型资源对象，给出 `name`、`path`、`readSettings()`、`fileURL(reference)` 和 `dispose()`，并使用现有场景加载流程。

## GitHub Pages

站点使用相对路径，支持部署到仓库子路径。在仓库的 **Settings → Pages** 中选择从分支部署，再选择包含这些文件的分支以及 `/ (root)`。
