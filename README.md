# L2D Viewer

静态 Live2D 模型查看器。支持从本地文件夹添加 Cubism 模型、在同一画布显示多个模型，以及查看、编辑和交换姿势参数。读取的模型文件留在浏览器中。

## 运行

无需安装 npm 依赖或构建。在仓库目录运行：

```sh
python3 -m http.server 8765
```

用支持文件夹选择、WebGL 和 Popover API 的现代浏览器打开 `http://localhost:8765/`。浏览器需要加载 jsDelivr 上的 PixiJS 和 Live2D 适配器，以及 Live2D 官方站点上的 Cubism Core。

要试用仓库中的三个样本，可在页面上一次导入整个 `resources` 文件夹，查看各模型自动播放的第一个动作。

## 使用

1. 点「+」，选择包含 `.model3.json`、`.moc3` 及其所引用贴图和动作等文件的文件夹。可以选择包含多套模型的上级文件夹，也可以反复添加。旧版 `.model.json` 暂不支持。
2. 模型默认叠放在画布左侧。点击模型本身或功能栏里的模型标签可选中，再点一次可取消选中。横向拖动标签调整图层，右侧标签对应更上层的模型，也可聚焦标签后用 Shift 加左右方向键调整。
3. 导入后会打开右下角的「模型变换」。按住移动或旋转按钮会立即开始连续调整，缩放按钮每点一次调整一步。也可直接输入数值。X 正值向右，Y 正值向下，正角度为顺时针，大小以默认尺寸的百分比表示。位置、角度和大小可分别重置。「复制」会创建独立副本，保留变换、表情和当前姿势，并从暂停开始。
4. 每个模型导入后会循环播放自己的第一个动作。从首个动作切换到其他动作时默认单次播放，切回首个动作时默认循环，可用开关手动调整。「（重）播放」可从头播放所选动作。参数检查器有「动作参数」和「表情参数」标签。模型中同时用于动作和表情的参数在两栏都能编辑。暂停后可调整参数，单项重置图标和「重置全部参数」可恢复默认值。悬浮在参数 ID 上可查看描述。两个浮窗都可通过标题栏拖动，若标题栏拖出了屏幕，可从功能栏关闭再重新打开以恢复位置。
5. 「JSON 快照」只导出偏离默认值的参数，格式为 `{"ParamAngleX": 10}`。全部处于默认值时会导出 `{}`。导入会校验参数 ID 和数值范围，再暂停并应用列出的值。
6. 用功能栏上的太阳和月亮开关切换浅色或深色主题，或通过「背景」设置画布纯色和本地图片。取消「固定」后，功能栏在鼠标移出时自动收起，鼠标移到网页顶边任意位置即可展开。
7. 主题开关右侧的下拉框可切换中文和 English。浏览器会记住所选语言。模型文件中的参数名称、动作名称和表情名称按原文显示。

「模型变换」中的鼠标操控默认关闭。开启后可以在画布上拖动模型，在模型上滚动滚轮可缩放。多个模型重叠时，鼠标操作当前所指位置最上层的模型。

## 结构

- `src/local-model-source.js` 发现本地模型，通过模型文件的相对路径解析资源。
- `src/live2d-model.js` 封装渲染适配器、单模型播放状态、姿势参数和快照。
- `src/scene.js` 管理共用画布上的模型位置、图层、选中和生命周期。
- `src/parameter-panel.js` 渲染参数面板。`src/main.js` 连接导入、场景和页面控件。
- `src/model-strip.js` 管理横向模型列表。`src/animation-controls.js` 和 `src/transform-controls.js` 分别连接动作表情和位置角度控制。
- `src/canvas-controls.js` 管理画布点击、鼠标拖动和滚轮缩放。
- `src/workspace-controls.js` 管理主题、背景和浮动功能栏。
- `src/i18n.js` 管理界面文案和语言选择。

未来的远端模型列表可以生成同样的模型资源对象，给出 `name`、`path`、`readSettings()`、`fileURL(reference)`、`clone()` 和 `dispose()`，并使用现有场景加载流程。
