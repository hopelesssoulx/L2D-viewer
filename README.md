# L2D Viewer

静态 Live2D 模型查看器。支持从仓库资源列表、本地文件夹或模型链接添加 Cubism 模型，在同一画布显示多个模型，以及查看、编辑和交换姿势参数。读取的本地文件留在浏览器中。

## 运行

无需安装 npm 依赖或构建。在仓库目录运行：

```sh
python3 -m http.server 8765
```

用支持文件夹选择、WebGL 和 Popover API 的现代浏览器打开 `http://localhost:8765/`。浏览器需要加载 PixiJS、Live2D 适配器以及 Cubism 2.1 和 Cubism 3+ 的运行库。

可导入 `resources` 里的单个样本、游戏文件夹或整个 `resources`。`bd-gbp` 的服装模型共享同级目录下的动作和表情，从本地导入时请选择整个 `bd-gbp` 或其上级文件夹。导入后会显示各模型的默认姿势，并运行 Cubism 的摇摆、呼吸和模型支持的自动眨眼。

## 使用

1. 从「+」右侧的「仓库模型」下拉框选中样本即可添加。把包含 `.model3.json` 或 Cubism 2 `model.json` 及其所引用资源的文件夹拖入页面，也可以点「+」从本地选择。这两种方式都支持导入包含多套模型的上级文件夹。
   在功能栏输入 `.model3.json` 或 `model.json` 的直链，再点「链接导入」或按 Enter。通过 HTTPS 打开查看器时请使用 HTTPS 模型链接。跨站模型的描述文件和引用资源需要允许跨域访问（CORS）。
2. 模型默认叠放在画布左侧。点击模型本身或功能栏里的模型标签可选中，再点一次可取消选中。横向拖动标签调整图层，右侧标签对应更上层的模型，也可聚焦标签后用 Shift 加左右方向键调整。
3. 导入后会打开右下角的「变换」。方向按钮每步移动 20 px，按住移动或旋转按钮会立即开始连续调整，缩放按钮每点一次调整一步。也可直接输入数值。X 正值向右，Y 正值向下，正角度为顺时针，大小以默认尺寸的百分比表示。位置、角度和大小可分别重置。「复制」会创建独立副本，保留变换、表情和当前姿势，并从暂停开始。
4. 加载模型后会打开「动作和表情」浮窗，左侧选择动作，右侧切换表情。可用功能栏同名按钮重新打开。每个模型默认单次播放，循环开关的设置会保留到切换后的动作。选择「无动作」会停止动作并恢复默认姿势和当前表情。单次动作结束后，模型以末帧为基础姿势，自动效果继续运行。暂停时切换动作会停在新动作的首帧，切换表情会直接显示新表情。「（重）播放」可从头播放所选动作。「参数」面板有「动作参数」和「表情参数」标签。模型中同时用于动作和表情的参数在两栏都能编辑。暂停后可调整参数，单项重置图标和「重置全部参数」可恢复默认值。悬浮在参数 ID 上可查看描述。浮窗都可通过标题栏拖动，若标题栏拖出了屏幕，可从功能栏关闭再重新打开以恢复位置。
5. 「JSON 快照」只导出偏离默认值的参数，格式为 `{"ParamAngleX": 10}`。全部处于默认值时会导出 `{}`。导入会校验参数 ID 和数值范围，再暂停并应用列出的值。
6. 用功能栏上的太阳和月亮开关切换浅色或深色主题，或通过「背景」设置画布纯色和本地图片。取消「固定」后，功能栏在鼠标移出时自动收起，鼠标移到网页顶边任意位置即可展开。
7. 主题开关右侧的下拉框可切换中文和 English。浏览器会记住所选语言。模型文件中的参数名称、动作名称和表情名称按原文显示。

「变换」中的鼠标操控默认关闭。开启后可以在画布上拖动模型，在模型上滚动滚轮可缩放。多个模型重叠时，鼠标操作当前所指位置最上层的模型。

「参数」面板的循环开关后面显示当前动作帧。拖动进度条或输入帧号会暂停并预览该帧，点「继续」可从所选帧接着播放。帧号从 0 开始，范围取自动作的时长和帧率。

## 结构

- `src/local-model-source.js` 发现本地模型，通过模型文件的相对路径解析资源。
- `src/resource-model-source.js` 读取 `resources/models.json`，用站点上的相对地址加载仓库模型。新增仓库样本时，将相对于 `resources` 的模型描述文件路径加到列表中。
- `src/url-model-source.js` 加载链接指向的模型描述文件，并解析相对资源路径。
- `src/live2d-model.js` 封装渲染适配器、单模型播放状态、姿势参数和快照。
- `src/cubism2.js` 连接 Cubism 2.1 的参数、表情混合和动作时间轴。
- `src/scene.js` 管理共用画布上的模型位置、图层、选中和生命周期。
- `src/parameter-panel.js` 渲染参数面板。`src/main.js` 连接导入、场景和页面控件。
- `src/model-strip.js` 管理横向模型列表。`src/animation-controls.js` 和 `src/transform-controls.js` 分别连接动作表情和位置角度控制。
- `src/canvas-controls.js` 管理画布点击、鼠标拖动和滚轮缩放。
- `src/workspace-controls.js` 管理主题、背景和浮动功能栏。
- `src/i18n.js` 管理界面文案和语言选择。
